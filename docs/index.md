# Pyrop

Pyrop is a small, statically typed language for complete programs in the terminal: utilities, text adventures, games and dashboards. It has no brackets and no symbols. Every operation comes first and takes a fixed number of arguments, so a line reads aloud as it is written:

```
write_line add "Hello, " ask "What is your name? "
```
